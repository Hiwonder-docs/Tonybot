# 7. Group Control

## 7.1 Project Introduction

This section demonstrates controlling multiple robots via a mobile device.

## 7.2 Program Download

1)  Open the **[Hiwonder Python editor]()** and load the **[main.py]()** file for group control.

<img class="common_img" src="../_static/media/chapter_7\section_1\media\image1.png" style="width:500px" />

2)  Modify the Wi-Fi name and password to match those of the local network.

<img class="common_img" src="../_static/media/chapter_7\section_1\media\image1.png" style="width:500px" />

3)  Connect the robot and download the **main.py** file onto the robot. Please note that each robot to be controlled requires this download. Once the download is complete, disconnect the data cable, power off the device, and reboot.

<img class="common_img" src="../_static/media/chapter_7\section_1\media\image2.png" style="width:500px" />

## 7.3 Operation Steps

1)  Connect both the mobile device and robots to the same Wi-Fi network. Open the group control app and select the corresponding robot.

<img class="common_img" src="../_static/media/chapter_7\section_1\media\image3.jpeg" style="width:500px"  />

2)  Tap the refresh button to see the robots connected to the same Wi-Fi network.

<img class="common_img" src="../_static/media/chapter_7\section_1\media\image4.png" style="width:500px"  />

3)  Next, tap the **Action group control** button to choose a default action group. All robots will execute the selected action simultaneously.

<img class="common_img" src="../_static/media/chapter_7\section_1\media\image5.png" style="width:500px" />

4)  Tap the **Add** button to create a custom action group. For custom action groups, they must first be imported into each robot via the PC software. Once imported, all robots will execute the custom action group.

<img class="common_img" src="../_static/media/chapter_7\section_1/media/image6.png" style="width:500px" />
